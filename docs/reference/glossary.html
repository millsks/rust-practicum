A

Arc
Arc<T> (atomically reference-counted) gives shared ownership of a heap value across threads; cloning it bumps a counter instead of copying the value. Pixi passes Arc-wrapped state between async tasks everywhere. M08 Smart Pointers & Shared State
Associated type
A type named inside a trait that each implementation fills in, such as Iterator::Item. It lets a trait talk about related types without a generic parameter. M06 Traits & Generics
async / await
async fn returns a future, a value that does nothing until it is polled; .await waits for one. Pixi runs its futures on the tokio runtime. Roadmap: Stage 5 (planned)

B

Blanket implementation
An impl<T: Bound> Trait for T that implements a trait for every type meeting a bound. Pixi's FromTomlStr is implemented this way for every toml_span::Deserialize type. M06 Traits & Generics
Borrow
Taking a reference (&x or &mut x) to a value without taking ownership. The owner keeps the value and gets it back when the borrow ends. M03 Ownership & Borrowing
Borrow checker
The part of the compiler that enforces the borrowing rules: any number of shared references or exactly one mutable reference, and no reference outliving its value. M03 Ownership & Borrowing
Box
Box<T> owns a single value on the heap. It is used for recursive types, large values, and trait objects (Box<dyn Trait>). M08 Smart Pointers & Shared State

C

Cargo
Rust's build tool and package manager: it compiles crates, fetches dependencies from crates.io, and runs tests. In this course it comes from pixi add rust and runs as pixi run cargo .... M01 Cargo, Crates & Modules
Cargo feature
A named, optional part of a crate declared in [features], turned on by dependents and tested with #[cfg(feature = "...")]. Pixi uses default-features = false on every rattler crate to choose features explicitly. M10 Visibility, Features & Crate Design
Cargo.lock
The file that records the exact version of every dependency in a build, like pixi.lock. Commit it for binaries and workspaces. M01 Cargo, Crates & Modules
cfg attribute
#[cfg(...)] compiles an item only when a condition holds, such as test, a feature, or target_os = "windows". Code that is configured out is not compiled at all. M10 Visibility, Features & Crate Design
Clippy
Rust's official linter, run with pixi run cargo clippy. Pixi treats every warning as an error (-D warnings) and configures it in clippy.toml. M11 Testing Like Pixi Does
Clone
The trait for making an explicit, possibly expensive, copy of a value with .clone(). Cloning is how you keep using a value after giving a copy away. M03 Ownership & Borrowing
Closure
An anonymous function that can capture variables from its surroundings, written |x| x + 1. How it captures decides whether it implements Fn, FnMut, or FnOnce. M09 Closures & Iterator Chains
collect
The iterator consumer that builds a collection from an iterator. The target type (Vec, HashMap, String, even Result<Vec<_>, E>) comes from the annotation. M05 Collections & Iterators
Command dispatcher
Pixi's CommandDispatcher (crate pixi_command_dispatcher): a handle for running a graph of interdependent operations, such as solves, source checkouts, and builds, concurrently without repeating work. Pixi Codebase Map
Compute engine
Pixi's pixi_compute_engine crate: a generic engine where each unit of work is a Key; it deduplicates concurrent requests, caches results, and detects cycles. Pixi Codebase Map
Copy
A marker trait for types whose values are duplicated by a plain bit copy, such as integers, bool, and char. Assigning a Copy value copies it instead of moving it. M03 Ownership & Borrowing
Crate
The unit of compilation in Rust, built from one root file and its modules: a library crate (src/lib.rs) or a binary crate with main (src/main.rs). A package contains one or more crates. M01 Cargo, Crates & Modules

D

Debug
The formatting trait used by {:?}, meant for developers. You almost always derive it. M06 Traits & Generics
Derive
#[derive(...)] asks the compiler to generate trait implementations, such as Debug, Clone, and PartialEq, from a type's fields. It is Rust's answer to @dataclass. M02 Types, Structs & Enums
Display
The formatting trait used by {} and .to_string(), meant for users. You implement it by hand. M06 Traits & Generics
Doc comment
A comment that becomes documentation: /// documents the next item and //! documents the enclosing module or crate. cargo doc renders them. M10 Visibility, Features & Crate Design
Drop
The trait whose drop method runs when a value goes out of scope. It is how files close and locks release without a with block. M03 Ownership & Borrowing
dyn Trait
A trait object type: a value of some type that implements the trait, chosen at runtime and called through a vtable. It must sit behind a pointer such as &dyn Trait or Box<dyn Trait>. M06 Traits & Generics

E

Edition
A set of language changes a crate opts into in Cargo.toml (edition = "2024"). Crates of different editions work together; the course and Pixi use edition 2024. M01 Cargo, Crates & Modules
Enum
A type whose value is one of several variants, each of which can carry its own data. Combined with match, it replaces class hierarchies and tagged unions. M02 Types, Structs & Enums
Error code
Every compiler error has a code such as E0382 (use of moved value) or E0502 (conflicting borrows). rustc --explain E0382 prints a full explanation. M00 How This Practicum Works

F

Fn, FnMut, FnOnce
The three closure traits: Fn can be called many times through a shared reference, FnMut needs mutable access, and FnOnce may be called only once because it consumes what it captured. M09 Closures & Iterator Chains
From / Into
Conversion traits: implementing From<A> for B gives B::from(a) and a.into(). The ? operator uses From to convert error types. M06 Traits & Generics
Frozen snapshot
The single Pixi commit, 451aa959, that every course permalink and quoted excerpt points at, so line numbers never drift. M00 How This Practicum Works

G

Generic
Code with type parameters, such as fn largest<T: PartialOrd>(items: &[T]), checked once and compiled for each concrete type used. M06 Traits & Generics

H

HashMap
A hash table from keys to values. Its iteration order is unspecified and changes between runs, so sort first or use BTreeMap, which keeps keys sorted. M05 Collections & Iterators
Heap
Memory for values whose size is not known at compile time or that must outlive a function call, such as the buffer of a String or Vec. It is freed when the owner is dropped. M03 Ownership & Borrowing

I

if let
Matches one pattern and runs a block only if it fits: if let Some(x) = maybe { ... }. Edition 2024 also allows let chains such as if let Some(x) = a && x > 3. M04 Option, Result & ?
impl block
A block that adds methods and associated functions to a type (impl Workspace { ... }) or implements a trait for it (impl Display for Workspace { ... }). M02 Types, Structs & Enums
impl Trait
In argument position, shorthand for a generic parameter with a bound; in return position, "some type that implements this trait" without naming it. Dispatch is static either way. M06 Traits & Generics
IndexMap
A map from the indexmap crate that keeps insertion order, like a Python dict. Pixi uses it so manifests keep the order you wrote. M05 Collections & Iterators
insta snapshot
A test that records output to a .snap file with insta::assert_snapshot! and fails when it changes. You accept or reject changes with cargo insta review; Pixi has thousands. M11 Testing Like Pixi Does
Interior mutability
Changing data through a shared reference, made safe by a type that checks access at runtime: Cell, RefCell, Mutex, or RwLock. M08 Smart Pointers & Shared State
Iterator
The trait with one required method, next(&mut self) -> Option<Self::Item>. Every adapter (map, filter) and consumer (collect, sum) is built on it. M09 Closures & Iterator Chains

L

lefthook
The Git hooks runner Pixi uses. lefthook.yaml lists the checks (cargo-fmt, clippy, typos, and more) and pixi run lint runs them all. Pixi Codebase Map
let-else
let Some(x) = maybe else { return ...; }; binds on a match and requires the else block to leave the scope otherwise. It keeps the happy path unindented. M04 Option, Result & ?
Lifetime
The region of code during which a reference is valid. Annotations like 'a describe relationships between lifetimes ("the result lives as long as the input"), not durations. M07 Lifetimes in Practice
Lifetime elision
The rules that let you omit lifetime annotations in common cases, such as a function with one reference parameter returning a reference. M07 Lifetimes in Practice
Lock file
In Pixi, pixi.lock: the exact packages solved for every environment and platform. Pixi reads and writes it with the rattler_lock crate. Roadmap: Stage 6 (planned)

M

Macro
Code that writes code at compile time, called with !: println!, vec!, format!. Attribute and derive macros such as #[derive(Debug)] are macros too. M00 How This Practicum Works
match
Rust's pattern-matching expression: it compares a value against patterns in order, binds the parts, and must be exhaustive. M02 Types, Structs & Enums
MatchSpec
The conda syntax for a package requirement, such as numpy >=2,<3 or conda-forge::python 3.14.*, and the type that represents it in rattler_conda_types. Roadmap: Stage 6 (planned)
miette
A crate for user-facing diagnostics with codes, labeled source spans, and help text. Most Pixi functions return miette::Result. M04 Option, Result & ?
Module
A namespace inside a crate declared with mod, usually one file. Items are private to their module unless marked pub. M01 Cargo, Crates & Modules
Monomorphization
How generics compile: the compiler makes a separate copy of a generic function for each concrete type it is used with. It makes generics as fast as hand-written code, at the cost of compile time and binary size. M06 Traits & Generics
Move
Transferring ownership of a value, by assignment, passing it to a function, or returning it. The old name can no longer be used (error E0382). M03 Ownership & Borrowing
move closure
A closure written move || ... that takes ownership of what it captures, needed when it outlives the current scope, as in thread::spawn. M09 Closures & Iterator Chains
MSRV
Minimum supported Rust version: the oldest compiler a crate promises to build with, set by rust-version in Cargo.toml. Pixi's is 1.90 while it builds with 1.95. M10 Visibility, Features & Crate Design
Mutex
Mutex<T> gives one thread at a time mutable access to T; lock() returns a guard that unlocks when dropped. Arc<Mutex<T>> is the usual way to share mutable state. M08 Smart Pointers & Shared State

N

nextest
cargo nextest, a faster test runner that runs each test in its own process. Pixi's test-fast task uses it. M11 Testing Like Pixi Does
Non-lexical lifetimes
The borrow checker's rule that a borrow ends at its last use, not at the end of its block, which accepts much more correct code. M03 Ownership & Borrowing

O

OnceLock / LazyLock
Standard types for values initialized once, on first use, and then shared: OnceLock is set explicitly, LazyLock runs a closure. They replace once_cell and lazy_static. M08 Smart Pointers & Shared State
Option
Option<T> is either Some(value) or None. It replaces None-able values, and the compiler makes you handle the None case. M04 Option, Result & ?
Orphan rule
You may implement a trait for a type only if your crate defines the trait or the type. It keeps two crates from writing conflicting implementations. M06 Traits & Generics
Ownership
Rust's memory model: every value has exactly one owner, ownership can move, and the value is dropped when its owner goes out of scope. It gives memory safety without a garbage collector. M03 Ownership & Borrowing

P

Package
What a Cargo.toml with a [package] table describes: a named, versioned bundle of one or more crates. M01 Cargo, Crates & Modules
Panic
An unrecoverable error that unwinds the current thread, from panic!, unwrap on None, or an out-of-bounds index. Use it for bugs, and Result for failures callers should handle. M04 Option, Result & ?
pub(crate)
Visibility that makes an item usable anywhere in the current crate but not outside it. pub(super) limits it to the parent module. M10 Visibility, Features & Crate Design

Q

Question-mark operator
? after a Result or Option: unwrap the success value, or return the error (converted with From) from the current function. M04 Option, Result & ?

R

RAII
Resource acquisition is initialization: tying a resource (memory, a file, a lock) to a value's lifetime, so it is released when the value is dropped. M03 Ownership & Borrowing
rattler
The family of Rust crates, also by prefix.dev, that implement conda: types, repodata fetching, solving, installing, and lock files. Pixi builds on them. Roadmap: Stage 6 (planned)
Rc
Rc<T> (reference-counted) gives shared ownership within one thread. It is not Send; use Arc across threads. M08 Smart Pointers & Shared State
RefCell
RefCell<T> moves the borrowing rules to runtime, allowing mutation through a shared reference within one thread; breaking the rules panics. M08 Smart Pointers & Shared State
Reference
A pointer that borrows a value: &T for shared, read-only access and &mut T for exclusive, mutable access. References never dangle. M03 Ownership & Borrowing
Repodata
The index of a conda channel for one platform: every package file with its name, version, build, and dependencies. Solvers read it to choose packages. Roadmap: Stage 6 (planned)
Result
Result<T, E> is either Ok(value) or Err(error). Rust uses it, not exceptions, for operations that can fail. M04 Option, Result & ?
rust-toolchain
A file at a project's root naming the exact Rust version to build with. Pixi's says 1.95.0. M00 How This Practicum Works

S

Send
A marker trait for types that are safe to move to another thread. The compiler implements it automatically; Rc is a common type that is not Send. M08 Smart Pointers & Shared State
Shadowing
Declaring a new variable with the same name as an earlier one (let x = x.trim();). The new binding can have a different type. M02 Types, Structs & Enums
Slice
A borrowed view into a contiguous sequence: &[T] into a Vec or array, and &str into a String. Functions take slices so callers keep ownership. M03 Ownership & Borrowing
Stack
Memory for a function's local values of known size, freed automatically when the function returns. Moving a String copies its small stack part, not its heap buffer. M03 Ownership & Borrowing
'static
The lifetime of the whole program. &'static str is a string literal; the bound T: 'static means T holds no short-lived references. M07 Lifetimes in Practice
String / &str
String is an owned, growable UTF-8 buffer; &str is a borrowed slice of UTF-8 text. Take &str in parameters and return String. M02 Types, Structs & Enums
Sync
A marker trait for types that are safe to share by reference between threads: T is Sync if &T is Send. M08 Smart Pointers & Shared State

T

thiserror
A crate whose derive macro generates Display, Error, and From implementations for error enums. Pixi defines most of its error types with it. M04 Option, Result & ?
tokio
The async runtime Pixi uses: it schedules futures on a pool of threads and provides async I/O, timers, and channels. #[tokio::test] runs an async test. Roadmap: Stage 5 (planned)
toml_edit
A TOML crate that edits a document while keeping its comments, order, and formatting. pixi add uses it, through pixi_toml_edit, to change pixi.toml. Roadmap: Stage 4 (planned)
Trait
A named set of methods that types can implement, like an interface or a Protocol that is checked at compile time. Traits can have default methods and associated types. M06 Traits & Generics
Trait bound
A requirement on a generic parameter, such as T: Display + Clone, written inline or, when it gets long, in a where clause after the signature. M06 Traits & Generics
Trait object
A value of type dyn Trait behind a pointer, whose methods are found at runtime through a vtable. It allows collections of different types that share a trait. M06 Traits & Generics

U

unwrap / expect
Methods that take the value out of an Option or Result and panic otherwise; expect adds a message. Acceptable in tests and for true invariants. M04 Option, Result & ?

V

Vec
Vec<T>, a growable array on the heap holding values of one type. It is Rust's list. M05 Collections & Iterators

W

Workspace
A set of packages built together with one Cargo.lock and target/ directory. Pixi's workspace has every crate under crates/ and pins shared versions once in [workspace.dependencies]. M01 Cargo, Crates & Modules
