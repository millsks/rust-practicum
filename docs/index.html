Rust Practicum

Learn the Rust you need to read, change, and review the Pixi codebase. The course is written for Python developers: every idea is tied to the Python you already know and to real code from a frozen snapshot of Pixi. Rust cells compile and run on the official Rust Playground from this page, exercises are graded by real cargo test output, and the capstones build locally with a Rust toolchain installed by Pixi.

How this course works

1 · Read and run

Lessons mix explanation with runnable cells. Edit the code and press Ctrl/⌘+Enter; it compiles on the Rust Playground.

2 · Argue with the compiler

"Compiler says no" cells show real errors on purpose. Reading error[E0382] calmly is the most useful Rust skill there is.

3 · See ownership

The ownership visualizer steps through moves, clones, and borrows on the stack and heap.

4 · Practice

Graded exercises run your code against #[test] functions. Hints and solutions are there when you need them.

5 · Read Pixi

Every module has a Pixi reading: real code from the frozen snapshot, explained line by line.

6 · Build

Each level ends with a capstone crate: pixi run start c1, then pixi run grade c1.

flowchart LR
  O[0 · Orientation] --> S1[Stage 1 · The core language] --> S2[Stage 2 · Idiomatic Rust] --> C1[Capstone 1 · Manifest reader]
  C1 -.-> L2[Level 2 · The Pixi stack] -.-> L3[Level 3 · Working in Pixi]

Level 1 (Reading Rust) is available now. Level 2 (errors, serde and TOML, async) and Level 3 (rattler, a tour of Pixi's architecture, and a change on a frozen Pixi snapshot) are on the roadmap.

All local work uses Pixi, which also installs Rust itself. From the repository root: pixi install once, pixi run serve to open this site, pixi run projects to list capstones, pixi run start c1 to copy a starter crate into work/, and pixi run grade c1 to run its tests.

Level 1 takes about 30-35 hours including the capstone. You need to be comfortable in Python: functions, classes, exceptions, dictionaries, and type hints. The Python Practicum covers all of it.
